## Pasos para la ejecución de los programas
+ 1.Edita las IP de en el código de los programas, tanto TCP como UDP (Constante HOST)
  - Para el caso de los servidores, cambia la IP por la IP de la máquina que sera servidor.
  - Para el caso de los clientes modifica la IP por la IP del servidor al que el cliente se conectara
+ 2.Ejecuta el programa con Python
  - Ejecuta el programa en una consola:
```bash
    python3 /ruta/programa.py
```
