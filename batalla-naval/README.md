# Resumend de actividad batalla naval
La actividad consistio en elaborar 2 escenarios en python de una batalla naval basado en el modelo clinte servidor y los protocolos TCP y UDP.
Como parte se seguir la base del curso, la conexión cliente servidor se hace por medio de sockets (relación IP-puerto).  Los programas hacian uso de la libreria socket.
La actividad se realizó en equipos, un alumno actuó como defensor (servidor) definiendo las coordenadas de sus barcos, y los demas actuarón como atacantes (clientes) quienes enviaban coordenadas hasta destruir todos los barcos del defensor.
